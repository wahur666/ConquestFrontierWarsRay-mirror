# Non-Frontend of Conquest

Date: 2026-08-29

This document copies the non-frontend file entries verbatim from [trim-framework-port-tracker.md](./trim-framework-port-tracker.md).

Filter rule: include tracker entries whose file names are not listed in [Frontend-of-Conquest.md](./Frontend-of-Conquest.md).

Likelihood guide:

- `High`: likely needed in the rewrite as a core app, framework, resource, runtime, or gameplay service.
- `Medium`: likely needed only if the rewrite keeps that feature set or behavior surface.
- `Low`: mostly reference material, compatibility support, or a narrower helper that should not drive architecture.
- `Very Low`: likely omit unless a legacy, legal, tooling, or debug requirement forces it back in.

Main functions/types: `StopNetConnection`, `SendZoneHostChange`, `StartNetConnection`, `GetHostIPAddress`, `AddressEnumStruct`. - `NetConnectBuffers.cpp`: packed temporary result buffers for enumerating connection providers, available sessions, and current players through DirectPlay; validates providers by initializing temporary DP instances, drives async session enumeration start/continue/stop, and adds a small amount of UI coupling through busy-cursor and join-failure message calls.
